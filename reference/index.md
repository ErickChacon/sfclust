# Package index

## All functions

- [`chapa`](chapa.md) : Spatio-temporal NDWI2 raster data from El
  Chaparrillo

- [`data_all()`](data_all.md) : Prepare data in long format

- [`filter_df()`](filter_df.md) : Filter a long-format data frame to
  valid spatial cells

- [`fitted(`*`<sfclust>`*`)`](fitted.sfclust.md) :

  Fitted Values for `sfclust` Objects

- [`genclust()`](genclust.md) : Generate initial cluster assignments

- [`log_mlik_all()`](log_mlik_all.md) : Fit models and compute the log
  marginal likelihood for all clusters

- [`plot(`*`<sfclust>`*`)`](plot.sfclust.md) :

  Plot function for `sfclust` objects

- [`plot_clusters_fitted()`](plot_clusters_fitted.md) : Plot functional
  shapes of cluster linear predictors

- [`plot_clusters_map()`](plot_clusters_map.md) : Plot a spatial map of
  cluster assignments

- [`plot_clusters_series()`](plot_clusters_series.md) : Plot observed
  time series by cluster

- [`plot_log_mlik()`](plot_log_mlik.md) : Plot log marginal likelihood
  convergence trace

- [`print(`*`<sfclust>`*`)`](print.sfclust.md) : Print method for
  sfclust objects

- [`sfclust()`](sfclust.md) : Bayesian spatial functional clustering

- [`stbinom`](stbinom.md) : Spatio-temporal Binomial data

- [`stgaus`](stgaus.md) : Spatio-temporal Gaussian data

- [`summary(`*`<sfclust>`*`)`](summary.sfclust.md) : Summary method for
  sfclust objects

- [`update(`*`<sfclust>`*`)`](update.sfclust.md) : Update MCMC
  Clustering Procedure
